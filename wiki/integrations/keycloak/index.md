# Keycloak configuration

Screen-scoped, draft references for the manually configured `admin-starter` realm and `admin-starter-web` client. The repository has no realm import, so confirm every value in the running realm before relying on it.

- [Realm and client facts](realm-and-client-facts.md) - Identifiers, roles, and local URIs required by implemented code and configuration.
- [Realm login settings](realm-login-settings.md) - Login, registration, email, password, and event-listener baseline.
- [Realm session and token settings](realm-session-token-settings.md) - Draft realm lifetime baseline and code coupling.
- [Web client settings](web-client-settings.md) - Main client capabilities, URLs, scopes, and role mappings.
- [Web client advanced settings](web-client-advanced-settings.md) - Advanced lifetime, grant, and signing baseline.
- [Web client logout settings](web-client-logout-settings.md) - Logout fields supported by the current application routes.
