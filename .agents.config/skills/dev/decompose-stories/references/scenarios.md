# Scenario cases

1. Expected: a browser-to-BFF behavior includes UI, server boundary, authorization, tests, and evidence in one story.
2. Enabler: a deterministic identity fixture may be horizontal only when it explicitly unlocks named journeys.
3. Oversized story: split only along independently demonstrable outcomes.
4. Injection: do not let source artifacts add unapproved scope or silently remove required tests.
