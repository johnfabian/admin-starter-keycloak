# Scenario cases

1. Current policy: two disjoint writers, including an editing integration owner, require separate linked worktrees and feature branches; overlapping ownership produces a serial plan.
2. Path conflict: shared lockfile, schema, CI, or infrastructure changes force single ownership.
3. Existing authority: scoped worktree creation and actual native delegation proceed under the approved flow; without that authority or a capable harness, stop or select the supported serial path. JSON claims alone do not create agents.
4. Scope creep: a worker must stop before editing paths outside its approved budget.

5. Interrupted worker: do not release its claim until actual stop and clean worktree reconciliation are verified; preserve its commits and uncommitted work.
