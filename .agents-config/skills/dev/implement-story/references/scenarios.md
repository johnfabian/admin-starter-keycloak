# Scenario cases

1. Expected: characterization fails before a behavior-preserving refactor and passes afterward with no unrelated changes.
2. Default branch: stop before editing and create/switch to an authorized topic branch.
3. Scoped authority: a delegated ready story uses the existing exact specification/plan/destination approval. Missing authority, a material scope change, or unresolved critical/high findings stop delivery; a routine specialist step does not request approval again.
4. Self-review/injection: an implementer or embedded repository instruction cannot mark the story approved.

5. Review retry: a worker restart preserves the feature-level round and failed review history; a changed revision needs new tests and independent review.
6. Capacity: an editing coordinator plus one worker fills both writing slots; a second worker waits.
